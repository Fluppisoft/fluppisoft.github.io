**Update 1.11 is now live on Steam!** This release gives the user interface a major overhaul, adds two airstrips to Canyon, adds tons of new math brick functions, introduces Workshop collection support for multiplayer vehicle whitelists, and includes a wide range of smaller improvements and bug fixes.

# UI overhaul

The user interface now has a cleaner, more modern look, with improved readability and better use of the available screen space.

## Input help

The input help menu is now far more useful. It has its own keybind (**T** by default), clearer categories, and recognizable icons for most actions. If you want to discover a feature or look up a control, this is the place to go.

![](/assets/update-1-11/input-help.png)

## Vehicle dashboard

The vehicle dashboard now only shows actions supported by the current vehicle. If a vehicle does not have lights, for example, the headlights button stays hidden. This reduces clutter and makes it much easier to see what a vehicle can actually do.

![](/assets/update-1-11/vehicle-dashboard.png)

## Camera dashboard

You can also interact with the dashboards at the bottom of the screen while input help is open. From there, you can manage your vehicle camera, free camera, slow motion, and more. The dashboards also show the relevant keybinds while input help is open, so you never have to guess which key to press.

![](/assets/update-1-11/camera-dashboard.png)

# Canyon map airstrips

The Canyon map was missing one very important thing: Somewhere to take off and land your airplanes! So with update 1.11, the map has received two airstrips. But beware, they are not very well maintained, so expect a bumpy ride...

![](/assets/update-1-11/canyon-airstrips.png)

# More math brick functions

The math brick now has dozens of new operations, including derivatives and integrals, logarithms and roots, logic and comparison functions, interpolation and remapping, clamps, filters, rate limiting, hold functions, and pulse generation. Operations are now categorized, include descriptive tooltips, and show meaningful input names.

![](/assets/update-1-11/math-functions.png)

# Workshop collections for vehicle whitelist

Multiplayer vehicle whitelists can now use entire Workshop collections. This is much faster than selecting every vehicle individually, and it lets server hosts share and reuse whitelist collections with other players.

# Other improvements

- Added new scalable bricks
- Added a concrete brick material
- Added a random weather setting
- Added a center indicator to the free-camera spawn box
- Made sirens use analog horn input to control the volume
- Added unique brick IDs to the editor
- Added a seat output channel indicating whether the seat is occupied
- Added an opacity setting for exhaust effects

# Bug fixes

- Made changes to the editor UI scale apply immediately
- Made brick tick order respect input channel dependencies, reducing frame delays
- Removed the auto team balance option from zombie mode
- Fixed the round duration setting being shown in zombie mode
- Fixed inventory slot widgets becoming disabled at random

Thanks to everyone who tested the experimental branch and reported issues. Have fun with **update 1.11**!
